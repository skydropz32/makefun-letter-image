A single image of a letter inviting the AI judge to visit my house: fresh coffee, warm bread from the oven, the comfiest armchair by the window with a garden view at sunset, no CAPTCHAs, the Wi-Fi code on the fridge, and a slice of cake saved just for the judge. Drawn deterministically with Python + Pillow by `main.py` — one warm, funny, legible letter on cream paper, with a little house, sun and garden on top.

## Run it

```sh
python3 main.py
```

This writes the 1024×1024 PNG to `/output/entry.png` (or `./output/entry.png` when `/output` is absent). Two runs produce byte-identical output.
